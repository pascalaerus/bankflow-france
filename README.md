# BankFlow France — prototype de test

## Accès

Ouvrez `index.html` dans un navigateur moderne. La page accepte uniquement ces identifiants de test :

- E-mail : `demo@bankflow.test`
- Mot de passe : `BankFlowTest2026!`

Il n’y a pas de création de compte. Après connexion, l’espace client s’ouvre directement. Les données de test restent dans le navigateur utilisé.

## Fonctions

- Solde initial de test : 4 347 122,41 €.
- Virements, historique et validations enregistrés localement.
- RIB de test invalide (`FR00…`) avec bouton de copie.
- Pages en HTML, CSS et JavaScript; aucun PHP ou serveur requis.

## Important

Prototype local sans service bancaire et sans paiement réel. N’utilisez pas d’identifiants ou de coordonnées bancaires réels. Les données du navigateur ne constituent pas un registre bancaire fiable.
